# javascript-learning

作業療法士からAIアプリケーションエンジニア転職を目指して独学中。
書籍『1冊ですべて身につく JavaScript 入門講座』（Mana 著／SBクリエイティブ）の学習記録リポジトリです。

## 学習環境

| ツール | 用途 |
| --- | --- |
| 書籍 | 『1冊ですべて身につく JavaScript 入門講座』（Mana／SBクリエイティブ／2023） |
| ブラウザ（開発者ツール） | コードの実行・コンソール確認・デバッグ |
| VS Code | コードの作成・保存・管理 |
| GitHub | 学習証跡の蓄積・公開 |

> Python学習ではGoogle Colabを使用していたが、JavaScriptではブラウザ上での実行を起点とする。
> コードの保存（VS Code）とGitHubでの公開・コミット運用はPython学習から継続。

## ディレクトリ構成

本書は章ごとに小さなWeb作品を作る構成のため、1章＝1フォルダ（HTML + CSS + JS のセット）で管理する。

```
javascript-learning/
├── ch02_hello/         CHAPTER 2 JavaScriptに触れてみよう
├── ch03_colorpicker/   CHAPTER 3 JavaScriptの基本を学ぼう（カラーピッカー）
├── ch04_events/        CHAPTER 4 イベントで操作しよう
├── ch05_data/          CHAPTER 5 複数のデータを使ってみよう
├── ch06_animation/     CHAPTER 6 アニメーションを加えよう
├── ch07_website/       CHAPTER 7 Webページを作ってみよう
├── ch08_errors/        CHAPTER 8 エラーと解決方法
└── notes/              章ごとの学習メモ（Markdown）
```

各章フォルダの構成:

```
chXX_xxxx/
├── index.html
├── css/style.css
└── js/script.js
```

※ CHAPTER 1 は概要解説のためコードなし。学習メモのみ `notes/ch01.md` に残す。

## 実行方法

各章フォルダの `index.html` をブラウザで開く。
VS Code の拡張機能「Live Server」を使うと、保存のたびに自動でリロードされる。

## 注意

書籍の配布サンプルデータは再配布にあたる可能性があるため、リポジトリには含めない（`.gitignore` で除外）。
本リポジトリに含めるのは、書籍を参考に自分で書いたコードのみ。
